# Аналітичне завдання 3 - Список (Linked list)

Python-програма з 9 задачами на однозв'язні списки. Користувач обирає номер задачі (1–9), вводить дані — і одразу отримує результат.

## Список задач

1. **Об'єднати два відсортовані списки** — зливає два відсортовані списки в один (два покажчики).
2. **Видалити дублікати з відсортованого списку** — прибирає повторювані значення, зберігаючи порядок.
3. **Цикл пов'язаного списку** — перевіряє наявність циклу (алгоритм «черепахи й зайця»).
4. **Перевпорядкувати список** — переставляє вузли у формі `L0 → Ln → L1 → Ln-1 → ...` (знайти середину, розвернути другу половину, злити).
5. **Видалити вузол у зв'язаному списку** — видаляє заданий вузол без доступу до голови (копіювання значення наступного вузла).
6. **Подвоїти число, представлене зв'язаним списком** — множить число на 2 з обробкою перенесення.
7. **Об'єднати k відсортованих списків** — зливає k списків в один через мін-купу.
8. **Розвернути вузли в k-групі** — розвертає кожні k вузлів; залишок менше k залишається як є.
9. **Розділити список** — усі вузли, менші за `x`, ставить перед вузлами `>= x`, зберігаючи порядок.

## Як користуватись
Програма покаже список задач, попросить номер (1–9), потім — дані. Після вводу одразу виведе результат.

## Валідація

Кожен ввід перевіряється згідно з обмеженнями задачі (діапазон значень, довжина списку, відсортованість, унікальність, коректність `pos`/`node`/`k`).
На некоректний ввід програма просить повторити.
